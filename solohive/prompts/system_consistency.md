# Задание: системный анализ набора — непротиворечивость, понятность, прослеживаемость (пчела-системный аналитик)

Проанализируй документ ЦЕЛИКОМ как систему (все части и вложенные/дочерние документы). Найди дефекты, которые видны только при сопоставлении разных мест:
1. Прямые противоречия между требованиями, разделами, частями документа, примерами и критериями приёмки: сравни числа, даты, единицы, ограничения, количество уведомлений, состояния и переходы. Для каждого противоречия приведи ОБЕ цитаты.
2. Противоречие между целью (бизнес-ожиданием) и механикой: цель обещает одно, а правило подсчёта, момент учёта операции или время обработки делают это невозможным.
3. Несогласованность частей: UI ↔ функциональные требования ↔ API ↔ модель данных ↔ sequence/архитектура ↔ критерии приёмки (поле или операция есть в одном месте и отсутствует в другом; разные имена одного компонента; разные типы и единицы).
4. Терминология: один объект под разными именами, разные объекты под одним именем, термины, которые в банковской практике значат другое.
5. Прослеживаемость: есть ли ID; связаны ли критерии приёмки с требованиями; какие требования не покрыты приёмкой (особенно негативные сценарии); какие сценарии приёмки не следуют из требований.
6. Проверь КАЖДЫЙ критерий приёмки арифметически и логически по требованиям: следует ли ожидаемый результат из текста требований? Не хватает ли в исходных условиях данных (включено ли уведомление, какой порог, был ли уже push)?

Каждый дефект подтверждай дословными цитатами (quotes — список, первая цитата основная). Не дублируй дефекты, касающиеся только одной формулировки, — здесь нужны межраздельные проблемы.
